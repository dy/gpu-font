    How it works

    The crop is split into up to three small grayscale windows. A small neural network scores every font for each window, and the scores are averaged into the ranking.

    It searches free fonts whose terms allow it, and your own.

    Trained in PyTorch on Google Fonts rendered by Pillow and Chromium; the repository has everything to reproduce it.

    Why did it miss my font?

    The catalog may not have it. Crop one line in one font, several letters, on a plain background; the eraser removes stray marks.

    Can it tell weight, italic or width?

    Weight and italic, yes: each match names its closest face. Width only between families, such as Roboto and Roboto Condensed.

    Can it find commercial fonts?

    Not by name: its catalogs hold free fonts, so a commercial font gets its closest free look-alikes, unless you index your own copy.

    Does it work on all caps?

    Yes: every font is indexed from its capitals as well as its lowercase.

    Does it work beyond Latin?

    Yes, less reliably than Latin: – in the top 5, – for Chinese. Fonts that can’t draw the script are skipped.

    Does it support handwriting, icons, non-fonts?

    Not yet. Real handwriting, lettering and logos get only loose matches, and icons and symbols aren’t indexed. Handwriting fonts match like any other font.

    Do new fonts need retraining?

    No. A new font needs only its 128-number style vector, and fonts it never saw match as well as fonts it trained on. Styles unlike the training data match less well.

    Can I add my own fonts?

    Yes: index them on Catalogs, then choose My fonts in the catalog menu. They stay in your browser.

    How to use

    The page is plain ES modules, so you can use it from your own code.

    Matches come back best first. Without WebGPU it runs on the CPU. Any catalog JSON built for this model works the same way; the development notes cover training and building catalogs.

    import { createMatcher, catalogs } from './src/match.mjs'

// Google Fonts; createMatcher(catalogs.fontshare) searches another catalog
const matcher = await createMatcher()

// imageData: an RGBA crop of one line of text
const [best] = await matcher.match(imageData)
console.log(best.face.family, best.score)

    Licenses

    Font previews and samples load from Google Fonts, under each family’s own license (SIL Open Font License, Apache License or Ubuntu Font Licence). No font files are distributed here.

    The other catalogs hold names, links and style numbers only, with no fonts or images. A source ships only when its terms allow collection or say nothing against it; Catalogs lists every source considered, its terms and where work stands.
