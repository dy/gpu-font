      Questions

      How accurate is it?
      On 5–10 characters of rendered text from 300 Google Fonts families it never saw, the right family (or an identical design) comes first – of the time and is in the top five –. Real screenshots aren’t measured yet. Scores are cosine similarity, not probability.
      Why did it miss my font?
      The selected catalog may not have it. It works best on one line in one font, several letters, on a plain background; the eraser removes stray marks.
      Can it tell weight, italic or width?
      Weight and italic, yes: every Google Fonts weight and italic is indexed, and each match names the closest. Width only between separate families, such as Roboto and Roboto Condensed.
      Which fonts can it find?
      Those in its catalogs: Google Fonts (except color and emoji fonts), Fontshare and Velvetyne. Anything else gets its closest look-alikes. Sources lists every source considered.
      Other scripts, handwriting, logos?
      Other scripts, yes, less reliably than Latin; fonts that can’t draw the detected script are skipped. Handwriting fonts, yes. Real handwriting, lettering and logos get loose matches only.
      Do new fonts need retraining?
      No: adding a font means computing its 128-number style vector, and the accuracy above is measured that way. Styles unlike the training data match less well; a retrained model needs every catalog rebuilt.
      Can I add my own fonts?
      Yes: build a catalog with the repository’s scripts and load it with “Open catalog JSON…”.
      Why WebGPU, and without it?
      WebGPU runs the model on the graphics card. Without it the CPU runs the same model, slower, with results equal to within 0.0001.
      How was it trained?
      A small convolutional network, trained in PyTorch on Google Fonts rendered by Pillow and Chromium, with 8-bit weights. The repository has everything to reproduce it.

      How to use

      The page is plain ES modules, so you can use it from your own code.

      Matches come back best first. Without WebGPU it runs on the CPU. Any catalog JSON built for this model works the same way; the README covers training and building catalogs.

      import { createMatcher } from './src/match.mjs'

const matcher = await createMatcher(
  'models/encoder/encoder.json', 'models/encoder/google-fonts.json')

// imageData: an RGBA crop of one line of text
const [best] = await matcher.match(imageData)
console.log(best.face.family, best.score)
